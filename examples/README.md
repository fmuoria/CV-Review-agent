# Example files

Sample CVs and cover letters for trying the tracker locally:

- `JohnDoe_CV.txt` + `JohnDoe_CoverLetter.txt` — experienced software engineer
- `JaneSmith_CV.txt` + `JaneSmith_CoverLetter.txt` — less experienced engineer
- `job_description.json` — the job description format the desktop agent used (kept for reference;
  jobs are now created in the dashboard)

To try them: start the app (see `docs/SETUP.md`), create a job, open **Upload CVs** and select all four
files. The `Name_CV` / `Name_CoverLetter` naming pairs each cover letter with its CV.
